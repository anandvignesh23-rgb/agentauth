# Demo Flow

1. Seed data with `npm run seed`.
2. Start the server with `npm start`.
3. Open `http://127.0.0.1:8787`.
4. Run `npm run demo`.
5. Watch the dashboard update with request counts, decisions, tokens, and audit events.
